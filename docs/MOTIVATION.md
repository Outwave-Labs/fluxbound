# Motivation

## Build something insane 🚀

A real-time 3D game/platform with physics, multiplayer, world editing, shaders, visual programming, user-generated content, and way more. Not another boring portfolio project.

## Become a much better engineer 🧠

We'll run into genuinely hard problems, break things, fix them, and learn how real systems actually work instead of just following tutorials.

## Build a portfolio that actually stands out 💼

A project this ambitious gives us something we can proudly put on our CV and send directly to recruiters, engineers, and companies.

## Get real team experience 🤝

Jira, GitHub, PRs, code reviews, architecture decisions, mentoring, and leadership - basically the experience of working on a real engineering team.

## Touch everything 🛠️

Graphics, networking, real-time systems, backend, databases, authentication, DevOps, performance, distributed state, and a ridiculous amount of other stuff.

## Build from scratch 🏗️

We get to make the big architectural decisions ourselves and see the consequences of those decisions, rather than inheriting someone else's 10-year-old codebase.

## Make something that could actually become a product 🎮

The goal isn't just to finish a GitHub project and move on. If we build something good enough, there's a real possibility of turning it into an actual game/platform.

## Work with people we actually like ❤️

No corporate bullshit, no time trackers, no fixed 9-5. Work when you have the time and motivation, while still building something together.

## Massive career upside 📈

Even if the game never becomes huge, the skills, experience, and project we'll have at the end can be an enormous advantage when going after top-tier engineering jobs.
